# 短篇頁面新增內容範例

短篇頁面共用 `source/_data/short_stories.yml`。編輯其中對應的故事即可更新內容；這份文件中的名稱、圖片與說明都是示意，不會顯示在網站上。

## 編輯既有故事

例如，在 `source/_data/short_stories.yml` 中，從 `  - id: bamboo` 開始，選到下一筆 `  - id: before-you-go` 之前為止，整段替換成下列內容。範例已包含正確的縮排，可直接貼上，再填入實際內容。保留既有的 `id`、`titleKey`、`category`，才會維持錨點、標題翻譯和文章分類的對應。

```yaml
  - id: bamboo
    titleKey: Where_the_Bamboo_Boat_Drifts
    intro:
      zh-tw: '這裡填寫一句故事簡介。'
      en: ''
      it: ''
    category: Bamboo
    galleryTag: null

    characters:
      - id: example-character
        name: 範例角色
        secondName: Example Character # 可省略
        avatar: /image/original/example-avatar.jpg # 可省略

    terminology:
      show: true
      # 需要連至其他作品的術語表時，取消下面的註解。
      # url: /Original/Final_Oath/#terminology
      # linkText:
      #   zh-tw: 查看共用術語
      items:
        - name:
            zh-tw: 術語名稱
            en: ''
            it: ''
          description:
            zh-tw: 這裡填寫術語說明。
            en: ''
            it: ''

    illustrations:
      - url: /image/original/example-illustration.jpg
        thumbnail: /image/original/example-thumbnail.jpg # 可省略
        caption:
          zh-tw: 圖片說明
          en: ''
          it: ''
```

其他故事同樣編輯各自的項目。沒有術語時可用 `terminology: null`；只有連結時可刪除 `items`；要預留空的術語區，可用 `show: true` 和 `items: []`。沒有角色或插圖時分別保留 `characters: []`、`illustrations: []`。

### 只新增角色

如果只想新增角色，請**整行替換**該故事原本的 `    characters: []`，不要把內容貼在 `[]` 裡面，也不要加 `{}`：

```yaml
    characters:
      - id: example-character
        name: 範例角色
        secondName: Example Character
        avatar: /image/original/example-avatar.jpg
      - id: another-character
        name: 另一位角色
```

以上縮排可直接貼回故事項目裡；每個 `- id:` 代表一個角色，`secondName` 和 `avatar` 可省略。示意圖片路徑需換成實際圖片。

## 角色詳細資料

角色卡片可先只填上方 `characters`；要讓卡片開啟角色 lightbox，另建角色 MD，例如：

```text
source/zh-tw/Original/Short_Stories/bamboo/ExampleCharacter/index.md
```

可複製現有角色 MD 作為起點，並設定與卡片相同的 `character.cardId`：

```yaml
character:
  cardId: example-character
  name: 範例角色
```

`bamboo` 必須與故事的 `id` 一致；`cardId` 請使用小寫並與卡片的 `id` 一致。沒有對應 MD 時，卡片仍會顯示，但不會開啟 lightbox。

## 加入故事文章

在 `source/_posts/zh-tw/Original/` 新增文章 MD，將分類設為該故事的 `category`。例如竹船使用 `Bamboo`：

```yaml
---
title: 範例文章標題
date: 2026-01-01 00:00:00
lang: zh-tw
slug: bamboo-example
categories:
  - [Bamboo]
---

這裡填寫文章內容。
```

文章會依分類自動列入故事的 STORY 區塊。其他既有分類為 `BeforeYouGo`、`Candle`、`APIB`、`WTY`；目前短篇頁面列出的是中文文章。

## 新增一個短篇區塊

在 `stories:` 陣列新增一筆，給它不重複的 `id`、`titleKey` 與文章 `category`，並在 `themes/landscape/languages/zh-tw.yml` 加入 `titleKey` 對應的故事名稱；英文與義文的標題也分別加在 `en.yml`、`it.yml`。側邊錨點選單會依故事資料自動產生。簡介、術語和圖片說明可依範例填寫 `zh-tw`、`en`、`it`；翻譯空白時會回退中文。

頁面最上方共用介紹則在同一個資料檔的 `overview.intro` 與 `overview.details`；頁面背景等設定在 `source/zh-tw/Original/Short_Stories/index.md`。
