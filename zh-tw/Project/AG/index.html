BIOGRAPHY

橙星學園二年級學生，日本人。非常喜歡星星，也非常喜歡自己的名字。家人只有極少聯絡的父親。有兩個很好的朋友和喜歡的人。

個性溫和且樂於助人，很容易受傷也很快就能恢復。不會因為別人討厭她而厭惡對方，對很多事都抱持著美好的想法，因此在有些地方很像笨蛋。會使用天文望遠鏡而不會用微波爐。有手機但常待在沒有訊號的地方所以也沒什麼作用。
興趣是觀星，放學後會跑到比較沒有光害的地方看星星。因為宿舍的門禁與觀星時間衝突，所以一個人住在外面。也因為半夜不睡覺的關係而常在上課時間打瞌睡。

想當偶像的原因是想成為地上的星星以及帶給別人希望。以前夢想成為觀星家，但因為種種因素而沒有實現。除唱歌以外並沒有出於常人的才能，就算是唱歌也僅在中上水準。拿手科目是外語，因許多天文書籍並沒有翻譯，所以連帶學會了其他國家的語言。

進入學園後喜歡上了學姊，放下過去的執念和學姊快樂的交往著。

ABOUT PROJECT

橙星學園

2018.02-2018.03

橙星學園(あかせ がくえん)建立於東京市內，是專門培育偶像的私立高中
投注了大量資金建設，擁有最先進的設備和豐富的資源，進而吸引許多擁有明星夢的少年少女們爭相入學
在學院內譜出一篇又一篇青春的樂章。
