BIOGRAPHY

林惜淵的女朋友，企劃時間軸已亡故，死因為自殺。

道德觀前衛，相當厭惡以世俗價值觀看待她與林惜淵關係的人，也討厭總是因為年紀輕就看扁她的人。
物慾很低，鮮少開口要求想要的東西，然而一但提了就一定要得到手。
個人經歷的緣故，對陌生男性會抱持異常警惕的態度。因為林惜淵身邊盡是些毀三觀的人，故培養了相當堅定的自主意識。

小時候經歷了一場綁架撕票案，正是林惜淵救下自己。在那之後被當作拖油瓶般在眾親戚間輾轉，過著被當作累贅的生活。因為受不了親戚間的流言蜚語，決定逃家並死纏爛打著要求林惜淵收養自己。長大後也靠著同樣的執傲成功讓林惜淵坦承對自己的渴望，因而在一起。

得知末日迫近時，因為不希望自己連死去的方式都無法決定。所以和林惜淵約好完成所有想做的事之後就自殺。但只有梁慕榕自殺成功，留下林惜淵獨自活著。

林惜淵死後一同轉生到了原創世界觀《Jatorri》，仍保有上一世的記憶，年齡與身體素質也相同。

ABOUT PROJECT

終焉的選擇題

2018.06-2018.12

世界每天都一點一滴崩壞著，時間的步伐緩慢逼迫而來，僅剩不到一年的時光。 一切都是註定好的結局，人類所能做的只是將這世界的結局收進眼底。

某日，​自稱是神明大人的少年出現在崩壞的廢墟中。
「我深愛著這世界，所以至少在最後一刻，我想看看所有人的結局。」 他笑著說，就像天真無邪的小孩開心地翻閱著繪本一樣。

神明大人給予了世人最後的選擇題，選擇題並沒有絕對正確的答案。
「那麼，好好思考吧，該怎麼樣利用最後這一段時間。」

這是殘存的世人所留下的最後一段故事，不存在希望、不存在救贖，於前方等待的是無可避免的終結。
還剩下231天。
距離世界消失，請善加利用最後這段時間，不要留下任何遺憾地迎接尾聲吧。
