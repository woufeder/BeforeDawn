BIOGRAPHY

冬城科大美術系大三生，單親出身，與母親的感情很好，極度厭惡自己的生父。
性格友善開朗，責任感強大。樂於學習新事物，對於所有事都抱持著開放的態度。
為減少母親的負擔而強迫自己早熟，也養成了把苦往肚子裡吞的性格。
對異性有不服輸的好勝心。力氣比普通女性大一點，擅長體力活，但並不喜歡運動。

國中時曾是於又綾的學生，從那時便一直喜歡她。但礙於身分以及當時社會對於同性戀愛仍有不少偏見，所以只將心意藏在心底沒有告訴她。直到去年偶然成為鄰居才又開始有所交流。

現在正一邊念書一邊打工存錢，希望等到有一定經濟實力後可以和於又綾步入婚姻

ABOUT PROJECT

永明高中

2020.07-2020.10

永明高中位於台灣北部，建立迄今已近百年。
校訓為「願智慧之光永恆長存」，同也是永明兩字的涵義。

雖然是升學向學校，但仍有各式各樣的學生。校園風氣開放，致力培養五育發展與全人教育。然而比起成績，更期勉學生能成為一個善良美好的人，並代代相傳。
